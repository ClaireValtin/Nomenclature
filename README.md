# Nomenclature

A variant converter: paste a variant in any format and get all its other notations (interface in French).

**Open it:** https://clairevaltin.github.io/Nomenclature/

## What it does

The same variant can be written in many ways. Nomenclature converts between them, in GRCh38 and GRCh37:

- HGVS `c.`, `g.` and `p.`
- rsID (dbSNP)
- VCF-style coordinates (e.g. `3-10149921-C-T`)
- SPDI
- gnomAD, GTEx and AlphaGenome Atlas identifiers

You can copy the results or export them as CSV. A built-in help page explains each nomenclature and why so many exist.

Conversions use Ensembl and NCBI Variation Services. Only the variant notation is sent to them. Never enter patient identifiers.

## How to use

Open the link above, paste a variant and press **Convertir**. Nothing to install.
