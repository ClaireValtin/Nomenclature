# Nomenclature

Convertisseur de variants : HGVS (c., g., p.), rsID, VCF, SPDI, gnomAD, GTEx, Open Targets et format AlphaGenome Atlas, en GRCh38 et GRCh37, avec une FAQ sur toutes les nomenclatures.

Page unique (`index.html`), sans dépendance à installer. Les conversions passent par les API publiques Ensembl REST et NCBI Variation Services ; seule la notation du variant leur est envoyée.

En ligne : https://clairevaltin.github.io/nomenclature/
